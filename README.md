# Fernet Encryption Tool

A simple Python encryption tool I made while learning more about cybersecurity.

## Features

* Generate encryption keys
* Encrypt messages
* Decrypt messages
* Simple terminal menu

## Requirements

```bash
pip install cryptography
```

## Run

```bash
python fernet_tool.py
```

## What I learned

* How Fernet encryption works
* How encryption keys are generated and used
* Python bytes when working with encrypted data
